BLM2537 Ağ Tabanlı Programlamaya Giriş dönem projesi. Evde hazırlanabilecek tatlı tariflerinin listelendiği ve kullanıcının kendi tarifini ekleyebildiği bir web sitesi.

## Nasıl çalıştırılır
1. Projeyi indirin veya klonlayın.
2. VS Code'da proje klasörünü açın.
3. VS Code'a Live Server eklentisini kurun.
4. index.html dosyasına sağ tıklayıp "Open with Live Server" seçeneğini seçin.

## Sayfalar
- index.html: ana sayfa
- tarifler.html: tarif listesi
- tarif-ekle.html: tarif ekleme

## Durum
1. hafta: HTML iskeleti tamamlandı.
