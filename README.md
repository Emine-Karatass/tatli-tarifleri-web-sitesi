# Tatlı Lezzetler

Evde kolayca hazırlanabilecek tatlı tariflerini bir araya getiren, kullanıcıların kendi tariflerini de ekleyebileceği bir web sitesi. BLM2537 Ağ Tabanlı Programlamaya Giriş dersi dönem projesidir.

## Özellikler

**Şu an çalışanlar**
- Ana sayfada günün tatlısı ve tarifi
- Tarifleri görsel, malzemeler, yapılış, zorluk ve süre ile gösteren tablo
- Malzeme ölçü karşılıkları tablosu
- Tarif ekleme formu
- Tüm sayfalarda ortak menü

**Planlananlar**
- JavaScript ile form doğrulama
- Tariflerin tarayıcıda (localStorage) saklanması, listelenmesi, güncellenmesi ve silinmesi
- Tarifleri zorluğa göre filtreleme veya isme göre arama
- Mobil cihazlarda düzgün görünüm

## Sayfalar

| Sayfa | Dosya | İçerik |
|---|---|---|
| Ana Sayfa | `index.html` | Tanıtım ve günün tatlısı |
| Tarif Listesi | `tarifler.html` | Görselli tarif tablosu |
| Tarif Ekle | `tarif-ekle.html` | Tarif ekleme formu |
| Ölçü Karşılıkları | `olculer.html` | Ölçü tablosu |
| Hakkımda | `hakkimda.html` | Sitenin amacı ve hazırlayan |

## Kullanılan teknolojiler
- HTML5
- CSS3
- JavaScript (planlanan)
- localStorage (planlanan)

## Nasıl çalıştırılır
1. Depoyu indirin (**Code > Download ZIP**) ya da `git clone` ile klonlayın.
2. Proje klasörünü VS Code ile açın.
3. VS Code'a **Live Server** eklentisini kurun.
4. `index.html` dosyasına sağ tıklayıp **Open with Live Server** seçeneğini seçin.
